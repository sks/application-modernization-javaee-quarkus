# Migration Phases

1. Phase 1: Strangled Catalog: Extract item catalog to Quarkus.
2. Phase 2: Frontend Split: Introduce Single-SPA and Vue.js widgets.
3. Phase 3: Service Isolation: Move remaining monolith logic to Open Liberty.
4. Phase 4: Persistence Decoupling: Transition from Db2 to Postgres for catalog.
5. Phase 5: Cloud Native Ops: Full Tekton and ArgoCD automation.
